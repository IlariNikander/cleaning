# Siivouspisteet

Yhden sivun GitHub Pages -sivu kotitöiden pisteytykseen.

- Jokaisella kotityöllä on oma kortti ja pistearvo.
- Valinta: K, I tai tyhjä.
- Valinnat tallentuvat selaimen localStorageen.
- Historiaa ei tallenneta.
- K:n ja I:n yhteispisteet näkyvät sivun yläreunassa.
- Yksittäisen kortin tai koko tilanteen voi tyhjentää.

Kotitöitä muokataan `index.html`-tiedoston `const chores = [...]` -kohdasta.
